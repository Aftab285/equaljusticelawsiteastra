# Equal Justice Lawyers — Website (Astro)

A high-performance, responsive, and SEO-architected website for **Equal Justice Lawyers**, representing individuals and families across California in personal injury, employment law, disability rights, medical malpractice, and consumer protection.

Built with [Astro](https://astro.build/).

## 🏛️ Features

- **Master Design System**: Crafted around the approved brand aesthetics with Playfair Display, Inter, and Great Vibes fonts, gold accents (`#c8a04a`), and deep night forest greens (`#1a3328`, `#122019`).
- **Comprehensive Page Network (40+ Static Routes)**:
  - Complete English and Spanish (`/es`) homepages.
  - Deep-dive Practice Area pages with statutory citations and evidence checklists.
  - California regional hubs across Greater LA, Orange County, San Diego, Inland Empire, Bay Area, Silicon Valley, Sacramento, and Central Valley.
  - California Legal Resources and statutory guides.
  - Contact, About, and intake evaluation flows.
- **Interactive Intake Assistant**: Zero-dependency conversational drawer modal with bilingual support (EN/ES) and ethics compliance.
- **Progressive Case Evaluation Wizard**: Multi-step confidential case evaluation form.
- **Ethics & State Bar Compliance**: Non-attorney disclaimers, advertising disclosures, and multi-jurisdictional notices.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm`

### Installation
```sh
npm install
```

### Development
```sh
npm run dev
```
Local development server will run at: [http://localhost:4321/](http://localhost:4321/)

### Production Build
```sh
npm run build
```
Generates the fully optimized static build inside the `dist/` directory.

### Preview
```sh
npm run preview
# or run the custom static server:
node server.mjs
```
